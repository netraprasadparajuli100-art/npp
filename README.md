# Netra Prasad Parajuli — Personal Website

A responsive HTML/CSS/JavaScript portfolio website based on the supplied Curriculum Vitae.

## Files
- `index.html` — website structure/content
- `css/style.css` — design, responsive layout and animations
- `js/script.js` — loader, mobile navigation, scroll effects, theme button and back-to-top
- `images/` — put Netra Prasad Parajuli's photos here

## Before publishing
1. Replace the profile placeholder in `index.html` with a real photo.
2. Put the photo in `images/` and update the `<img>` path.
3. Replace/add real project photographs in the Technical Work/Gallery section.
4. Review the phone number and other public contact details before publishing.
5. Add the custom domain in GitHub Pages.

## GitHub Pages
Repository -> Settings -> Pages -> Deploy from a branch -> main -> / (root).

For the custom domain, create a file named `CNAME` in the repository root containing:

netraprasadparajuli.com.np

Then configure DNS at the domain provider with the GitHub Pages records GitHub displays for the repository.
